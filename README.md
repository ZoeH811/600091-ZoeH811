# Fitness Planner & Tracker Application

## Project Status: In Development

## Project Type: Honours Stage Project  

## Development Framework: .NET MAUI (.NET 10 LTS)

## Target Platforms: Android and iOS

## Overview

This repository will contain the relevant source code for the application and the supporting development documentation for the Fitness Planner and Tracker Application.

This project aims to develop a cross-platform mobile application that supports users in planning, recording and monitoring their physical activities through personalised training plans, progression visualisations and interactive gamification features.

A key aspect of the application will be the integration of the virtual pet as a gamified feature and adventure-based progression system which intends to encourage user engagement and provide additional motivation to users for maintaining physical activity and fitness goals.

The application is being developed within .NET MAUI.
